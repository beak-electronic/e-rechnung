Version: 2.3

Schnellweg: Netlify Drop (kostenlos, kein Apple-Account)

1. Ordner e-rechnung bereithalten
   Optional: zip -r e-rechnung-netlify.zip -C e-rechnung .  (Inhalt mit index.html oben)
2. Im Browser https://app.netlify.com/drop öffnen
3. Den Ordner e-rechnung (nicht nur einzelne Dateien) per Drag-and-Drop hochladen
   Publish-Root = Ordnerinhalt mit index.html, netlify.toml, sw.js — kein Build-Befehl nötig
4. Die angezeigte https://….netlify.app URL notieren
5. Auf dem iPad Safari diese URL öffnen
6. Teilen-Taste → „Zum Home-Bildschirm“ → Hinzufügen
7. App-Icon „E-Rechnung“ starten (Standalone, offline nach erstem Laden)


Windows / Google Chrome (App installieren)
-----------------------------------------
Voraussetzung: App unter https://… (z. B. Netlify) — localhost geht auch.

1. In Chrome die App-URL öffnen
2. In der Adressleiste das Install-Symbol (Monitor mit Pfeil) anklicken
   oder Menü ⋮ → „E-Rechnung installieren“ / „App installieren“
3. Bestätigen — die App startet als eigenes Fenster (standalone)
4. Startmenü / Taskleiste: Icon „E-Rechnung“ (abgerundet wie iOS)

Install-Voraussetzungen (Chrome): gültiges Manifest mit display „standalone“,
Icons 192×192 und 512×512, registrierter Service Worker, HTTPS.


Hinweis: Service Worker und PWA brauchen https (Netlify liefert das).
Lokal zum Testen reicht: python3 -m http.server (siehe README).

Netlify Drawer abschalten (Site-Einstellungen)
----------------------------------------------
Die App blendet den Drawer per CSS aus (#netlify-drawer / .netlify-drawer), falls vorhanden.
Zusätzlich in Netlify dauerhaft deaktivieren:

1. Site öffnen → Project configuration (Site settings)
2. Build & deploy → Continuous Deployment → Collaboration tools → Configure
3. Netlify Drawer für Deploy Previews und Branch Deploys ausschalten
4. Speichern

PDF speichern / teilen auf dem iPad
-----------------------------------
Nach dem Erzeugen: navigator.share({ files: [pdf] }) nur mit files
(kein title/text/url) → „In Dateien sichern“. Fallback: Download.
In den Einstellungen kann die Speichern-Art gewählt werden.

Sicherheit / Inhalt der Zip
---------------------------
Die Deploy-Zip enthält KEINE Rechnungs-PDFs und keinen Ordner test/.
Nur App-Code, Icons, Fonts, Vendor-Libs. Beispielrechnungen bleiben lokal
unter test/ und dürfen nicht mit ausgeliefert werden.

Öffentliche Bundles / Anonymisierung
------------------------------------
Ordner /workspace/invoice-samples/ niemals in Deploy-ZIPs oder Public-Bundles legen.

Firmendaten: in der App leer; nur lokal speichern; Import/Export als TXT. Keine Firmendaten im Repo.
